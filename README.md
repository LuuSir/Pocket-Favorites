# ResourceTree 0.9

本地树状快捷资源管理器，保存文字、图片、视频和文件，并按条目设置执行复制、分享、启动应用或打开网页。

## 开始使用

- [下载发布版](https://github.com/LuuSir/ResourceTree/releases)；使用同签名 APK 覆盖更新，保留已有数据。
- 首页「＋ 新建」添加条目或文件夹；「更多」中置顶和批量整理，长按列表行拖拽排序。
- 点击左上角 ResourceTree 切换可缩放图视角。
- 「菜单 → 悬浮按钮」开启悬浮收集：单击直接读取并按规则预填，下拉通知栏添加「ResourceTree 悬浮窗」快捷开关，点亮开启、再点关闭。
- [B 站教程视频](https://www.bilibili.com/video/BV1dQYs6JEbT/?vd_source=6076e72eb03a33f77c50c30c9947e961)
