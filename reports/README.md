# ResourceTree 使用与维护

ResourceTree 将文字、图片、视频和文件组织成文件夹树，单击条目执行复制、启动应用、分享或打开网页。

| 功能 | 常用操作 |
| --- | --- |
| 条目与文件夹 | 首页「＋ 新建」；条目设置 Content 与 Action，目标应用可搜索选择 |
| 整理 | 长按列表行拖动排序；「更多」置顶、多选及批量移动、复制、删除；位置窗口使用面包屑导航 |
| 图视角 | 点击左上角 ResourceTree；点击文件夹进入，点击条目执行，双指缩放；「展开全部」显示当前目录所有后代 |
| 剪贴板规则 | 菜单中编辑匹配规则、通配符、动作和候选包名；匹配后仅预填，点击保存才入库 |
| 悬浮收集 | 菜单 → 悬浮按钮。单击在当前应用上方打开收集窗口，不经过首页；匹配后预填首页新条目，保存或取消后回到原应用 |
| 通知栏快捷开关 | 下拉通知栏 → 编辑快捷开关 → 添加「ResourceTree 悬浮窗」；点亮开启，再点关闭，状态与应用设置和通知中的关闭操作同步 |
| 悬浮尺寸 | 设置页调整 36–96 dp，默认 56 dp；尺寸和位置在关闭重开后保留 |
| 导入导出 | 菜单导入 JSON 会追加副本，不覆盖同名目录；导出 schema v2，兼容导入 v1 |

收集窗口复用已有编辑器和应用选择器，不覆盖主界面的未保存编辑。主动单击允许再次收集同一份剪贴板；无匹配规则时关闭窗口。敏感标记、非文本或过长的剪贴板不会预填。成功保存保持静默。

Android 10 起，读取剪贴板需要窗口获得焦点，因此会显示收集窗口，不进行后台持续监听。部分手机需允许「后台弹出界面」；未开启时可能无法从悬浮按钮打开窗口。长按透明锁定已移除，旧版锁定状态不再生效；悬浮按钮保持可见可点击。

首次点击快捷开关若未获悬浮窗权限，会进入系统授权页；授权后返回通知栏再点一次开启。快捷开关随服务实际运行状态亮灭，服务被系统终止后重新下拉会显示关闭。
